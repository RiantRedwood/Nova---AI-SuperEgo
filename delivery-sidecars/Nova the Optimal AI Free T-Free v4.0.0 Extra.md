# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness, or add the .zip to a project knowledge base in Chat. Attach or reference the .zip in chat and say, "Install this Augment." The prompt in this post is optional.

- After installation, ask Nova for the actual work: “Compare these offers and explain which differences matter,” “Repair this repository,” or “Turn these sources into a useful brief.” Read START-HERE.md inside the package for the route that fits your host.
- Keep the complete edition and rights files together. Use the packaged Codex plugin, Claude-compatible plugin or detached skill routes; a host must actually discover the capability before it is installed. The persona prompt works separately and supplies no tools or persistent storage by itself.
- Continue from the artifact or project you kept. Preserve external collections and the configured Nova estate when upgrading; existing save, capture, off and no-retention choices govern persistent state.
- For optional workspaces, follow docs/VISUAL-WORKSPACES.md and the selected skill's startup guide. Hosted local views need Python 3.10+; ordinary help does not. Keep examples, source material, working drafts and externally completed actions distinguishable, and download temporary working sets before closing their view.
- Keep the prior edition and your external data backup for rollback. Switch the host's installation route back to that compatible edition rather than replacing your working records.
