Start with the question, follow its evidence

This viewer reads native case files. It does not collect sources, create a case, save changes or verify a displayed ready label.

Your first inquiry

Give your assistant one question and the links or files you have. For example: “Compare these reports. Should the editor report a three-day terminal closure? Show the exact support and limits.” Ask it to preserve a native Observatory case and source captures if you need to return later. A one-off question can simply receive a bounded sourced answer.

For the fictional demonstration, return to the Atlas and choose Explore the synthetic case. Inspect the Gate B claim, read its source excerpt, then use Compare to see what changed. The local timezone is unknown; source repetition is not independent corroboration.

Find your way

Situation shows the last recorded assessment, cutoff and next move. Sequence separates known clock types. Evidence chains follows provenance, including observations. Records browses every type; Sources focuses on custody. Challenge preserves competing explanations. Compare requires revisions of the same inquiry.

Home retains the loaded investigation in that tab. Return to loaded investigation resumes it. Help opens this separate guide tab. The theme selector includes Daylight. Close a record or press Escape to return focus.

Load and recover

Use Investigation files to open your JSON and optional baseline. A malformed import retains the previous selection; fix it and select the same file again. Opening a different inquiry clears an unrelated baseline. Clear this investigation, reload or closing the tab removes in-memory data only. Your saved files stay intact.

For local hashes, exact source excerpts and stale review checks, run the native helper described in native case operations. The viewer uploads nothing, saves no browser data and activates no background watch.
